De un agente a un enjambre

Fase 1 introdujo el asistente IA. Fase 2 orquesta múltiples agentes especializados con contexto compartido entre todos.

🤖

Fase 1 — Un asistente

El autor redacta y consulta al asistente IA cuando quiere. Flujo lineal: redactar → revisar → publicar.

🧠

Fase 2 — Enjambre coordinado

El usuario configura y lanza un equipo de agentes especializados. Cada uno tiene un rol, herramientas y acceso al contexto compartido.

1

Los agentes disponibles

Cada agente está especializado en una tarea. El usuario los selecciona y configura desde el Agent Builder.

🧠

Agente Redactor

Genera y mejora contenido usando el LLM local. Recibe instrucciones del usuario y el contexto compartido del estado.

🔍

Agente Revisor

Verifica ortografía, gramática, coherencia y detecta errores de formato científico automáticamente.

🔬

Agente Investigador

Busca y recupera referencias relevantes desde Qdrant (RAG) y fuentes externas mediante Tavily.

📋

Agente Formateador

Aplica formato APA, IEEE o Vancouver al documento completo con un solo comando.

✨

Agente Publicador

Genera metadatos, portada y publica el artículo automáticamente tras la aprobación humana.

🎭

Orquestador (LangGraph)

Coordina el orden, gestiona el estado compartido y resuelve dependencias entre agentes con grafo de estados.

2

Contexto compartido entre agentes

Todos los agentes leen y escriben en el mismo estado. Ningún agente trabaja con información desactualizada.

LangGraph SharedState → Redis + PostgreSQL
state = {
  "title": "Impacto de los LLMs en la Educación Superior",

  "format": "APA 7ª",
  "references": ["Fernández et al. 2024", "Smith 2023"],
  "agent_log": ["Redactor: añadió párrafo 2", "Revisor: 3 correcciones"],
  "status": "pending_human_review"
}
📖

Lectura universal

Cada agente lee el estado antes de actuar. Nunca trabajan sobre texto obsoleto.

✏️

Escritura atómica

Los cambios se aplican de forma atómica con historial de versiones para rollback.

📜

Log completo

Cada acción queda registrada: quién la hizo, cuándo, qué cambió exactamente.

Ejecución paralela

Redactor, Revisor e Investigador corren simultáneamente. El orquestador espera a todos antes de continuar.

🔄

Feedback loop

Si el humano rechaza, el grafo vuelve a los agentes con el comentario de rechazo como nuevo input.

🛡️

Guardrails

Límites de tokens, rate limiting y rollback automático ante fallos. Ningún agente puede publicar sin aprobación humana.
